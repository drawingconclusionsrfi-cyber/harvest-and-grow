# Harvest & Grow — Demo Website

A fully self-contained demo website for a juice bar brand.

## 🚀 How to Use

**This is a single-file site — no setup needed.**

1. Download `index.html`
2. Open it in any browser — it works offline with no server required
3. Upload it to GitHub Pages, Netlify, or any static host

## 📁 Structure

```
harvest-and-grow/
└── index.html        ← Everything lives here (HTML + CSS + JS + SVGs)
```

All images are inline SVGs — no external files or broken image links.

## ✨ Features

- Responsive design (mobile, tablet, desktop)
- Sticky header with scroll effect
- Floating animated bottle illustrations
- Tabbed menu (Juices / Smoothies / Bowls)
- Add-to-order toast notifications
- Contact / order form
- Merch section
- Smooth scroll navigation
- Footer with social links

## 🌐 Deploy to GitHub Pages

1. Push `index.html` to a GitHub repo
2. Go to Settings → Pages → Source: main branch / root
3. Your site will be live at `https://yourusername.github.io/repo-name`

## 🎨 Customize

All colors are CSS variables at the top of the `<style>` block:

```css
--green-dark:   #1e3d2f;
--green:        #40916c;
--orange:       #e07a3a;
--cream:        #faf7f0;
```

Change fonts by swapping the Google Fonts import link.
